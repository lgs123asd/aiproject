## 二、在线问诊功能探索

### 2.1 在线问诊入口页（页面编号 P01）

**URL**: `/#/onlineConsultation/NewConsultationList`

两个入口：
- **西药处方**（图片按钮）
- **中药处方**（图片按钮）

### 2.2 共有的三步流程

两种处方类型均使用 3 步骤向导：

| 步骤 | 名称 | 说明 |
|------|------|------|
| 1 | 药品清单 | 搜索并选择首诊时开具的药品 |
| 2 | 就诊人信息 | 填写就诊人基本信息和首诊信息 |
| 3 | 预诊问答 | 回答预诊问卷，选择问诊方式提交 |

---

### 2.3 西药处方详细流程（页面编号 P02）

#### 步骤1：药品清单

**搜索加药**：
- 点击搜索框弹出"请选择首诊时医生开具的药品"对话框
  - 搜索框 placeholder: `请输入商品名称或者69码搜索`
  - 提示: "同时搜索两个以上条件,请用空格隔开示例: 阿莫西林 好医生"
  - 搜索结果：显示药品名称、规格、厂家，每条有"选择"按钮
  - 本次实测搜索"阿" → 共 4197 种药品，210 页
  - 分页：20条/页，支持跳页、切换每页条数
  - 底部：已选择 N 种药品 / "加入药品清单"按钮

**已选药品清单**（加入后变为表格模式）：

| 列名 | 说明 |
|------|------|
| 名称 | 药品名称（文本） |
| 规格 | 规格信息（文本） |
| 厂家 | 生产厂家（文本） |
| 用法 | combobox（如"口服"，可清空重选） |
| 单次用量 | spinbutton + 单位combobox（如 1 粒/0.5 袋，有 Increase/Decrease 按钮） |
| 用药频次 | combobox（如"每日三次"，可清空重选） |
| 操作 | 数量 textbox(含 -/+ 图标按钮) + "删除"链接 |

**处方金额**：选填文本框（单位：元）

**疾病诊断**：标签式选择，多个可选（本次实测选项）：
- 呼吸道感染、泌尿道感染、软组织感染、幽门螺旋杆菌感染、泌尿系统感染
- 消化系统幽门螺杆菌感染、关节痛、头痛、牙痛、发热、神经痛、流行性感冒

> 注：诊断列表可能根据所选药品动态变化，需后续验证。

**本次实操数据**：
- 搜索"阿" → 选择"阿司匹林维C泡腾片"（BayerVitalGmbH）+ "阿莫西林干混悬剂"（阿特维斯制药）
- 阿司匹林：口服，1粒，每日三次
- 阿莫西林：口服，0.5袋，每日三次
- 诊断：呼吸道感染

#### 步骤2：就诊人信息

**就诊人信息区域**：

| 字段 | 类型 | 必填 | placeholder |
|------|------|------|-------------|
| 姓名 | combobox(textbox) | * | 请输入姓名 |
| 性别 | radio | * | 男(默认选中)/女 |
| 年龄 | spinbutton(含+/-) | * | 请输入年龄 |
| 患者身份证 | textbox | 否 | 请输入身份证号 |
| 患者电话 | combobox(textbox) | 否 | 请输入手机号 |

**首诊信息区域**：

| 字段 | 类型 | 必填 | placeholder |
|------|------|------|-------------|
| 首诊机构 | textbox | 否 | 请填写首诊医院 |
| 首诊时间 | date-picker(readonly) | 否 | 请选择首诊时间 |

- **历史就诊人**按钮：可查看/选择历史就诊人（本次未展开）

#### 步骤3：预诊问答

**本次实操问答（基于阿司匹林+阿莫西林组合）**：

| 编号 | 问题 | 选项 | 本次选择 |
|------|------|------|---------|
| Q1 | 以往是否应用过所选药物？ | 是 / 否 | 是 |
| Q2 | 以往应用所选药物时有无过敏反应？ | 无过敏反应 / 有过敏反应 | 无过敏反应 |
| Q3 | 是否有其他β-内酰胺类（氨苄西林、哌拉西林、头孢等）药物过敏史？ | 无 / 有 | 无 |
| Q4 | 肾功能是否正常？ | 否 / 是 | 是 |
| Q5 | 是否有以下疾病或病史？ | 以上均无 / (可能更多) | 以上均无 |

⚠️ **疑点**：
- Q5 仅显示"以上均无"一个选项，未列出具体疾病列表 → 可能UI折叠或需配置
- 答案选中后视觉反馈不明显（标签颜色/样式未变化，仍显示 cursor=pointer）
- **非实时校验**：点击提交才提示"请回答完所有问题！"

**诊断确认**：步骤1选择的"呼吸道感染"在标签中锁定显示（🔒图标），支持更改

**提交按钮**：
- 视频问诊（含视频图标）
- 图文问诊（含图文图标）← **本次使用**

> 注：两个按钮点击后均显示 loading 状态，直到提交完成

#### 提交结果页

成功后显示：
- 问诊二维码图片
- 文字："问诊已提交"
- 提示："请使用手机微信扫码，到小程序上完成问诊。"
- "返回"按钮 → 返回 P01 在线问诊入口

### 2.4 中药处方详细流程（页面编号 P03）

#### 步骤1：药品清单（与西药关键差异）

| 差异点 | 西药处方 | 中药处方 |
|--------|---------|---------|
| 搜索 placeholder | "请输入商品名称或者69码搜索" | "请输入中药材名称搜索" |
| 搜索结果 | 含规格/厂家 | 仅药材名称 |
| 药品展示 | 表格(7列) | **卡片式**（名称+用量spinbutton+单位combobox） |
| 单药配置 | 用法/单次用量/用药频次 | **仅有用量和单位** |
| 全局设置 | 无 | **剂数/煎法/每日剂数/每日频次** |
| 经典方 | ❌ | ✅ "选择经典方"按钮 |
| 诊断选择 | 标签点击 | 搜索弹窗选择 |

**中药全局设置区域**：

| 设置 | 类型 | 默认值 |
|------|------|--------|
| 剂数 | spinbutton (±按钮) | 动态（经典方带入18剂） |
| 煎法 | combobox | 泡服/水煎服等 |
| 每日剂数 | combobox | 每日2剂 |
| 每日频次 | combobox | 每日两次 |
| 提示 | text | （每剂 N 味药）动态更新 |
| 处方金额 | textbox(选填) | — |

**本次实操数据**：
- 从经典方"测试感冒用药1"加载 → 车前草 2.50g + 杜仲 2.20ml + 黄芪 3.00g
- 手动搜索添加"当归" → 1.00g
- 共4味药，18剂，泡服，每日2剂，每日两次
- 处方金额：88.50元
- 诊断：感冒（搜索弹窗选择）

#### 诊断选择（中药特有弹窗）

| 特性 | 西药处方 | 中药处方 |
|------|---------|---------|
| 交互方式 | 点击标签直接选择 | 弹窗搜索 → 选择 → 确定 |
| 搜索 | 无 | 支持诊断名称搜索 |
| 结果展示 | 水平标签列表 | 垂直列表，每条有"添加这条诊断" |
| 取消/确定 | 无弹窗 | 有取消/确定按钮 |

本次搜索"感冒" → 共13条结果（普通感冒、风热感冒、风寒感冒、阴虚感冒等）

1. ✅ 系统支持两种登录方式：密码登录和验证码登录
2. ✅ 登录后必须选择药店机构才能进入系统

## 六、推断（基于页面表现）

1. 🔍 "视频问诊"需要消耗视频账户额度（首页显示剩余9张），"图文问诊"可能不消耗或消耗较少
2. 🔍 西药处方的诊断标签可能是系统预设的常用诊断
3. 🔍 中药经典方模板功能相当于"收藏夹"，方便药店快速复用常用处方
4. 🔍 首页弹出的"余额不足"弹窗可能是因为视频账户剩余数量低于系统阈值
5. 🔍 "历史就诊人"按钮暗示系统支持保存和复用过往就诊人信息
6. 🔍 中药预诊问题较少，可能因为中药风险模型与西药不同（无抗生素/肝肾风险）
7. 🔍 预诊问题内容根据所选药品动态生成（西药含阿莫西林→出现β-内酰胺类过敏问题）
8. 🔍 中药药材单位混用（g/ml），取决于药材形态（固体/液体）
