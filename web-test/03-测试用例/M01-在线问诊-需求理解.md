# 在线问诊 — 需求理解

> **来源**: `web-test/02-业务梳理/业务流程.md`  
> **生成日期**: 2026-06-21  
> **模块编号**: M01

---

## 1. 模块名称

在线问诊

## 2. 模块目标

为已登录药店用户提供在线开具处方问诊单的功能，支持西药处方和中药处方两条路径，最终通过图文问诊或视频问诊方式提交问诊单。

## 3. 涉及角色

| 角色 | 说明 | 需求来源 |
|------|------|---------|
| 已登录药店用户 | 代表某药店机构操作，可开具西药/中药处方 | 业务流程§1.1 |

> 未登录用户、注册、支付、后台管理、医生接诊角色均不在本轮测试范围。

## 4. 核心业务流程

### 4.1 流程总览

| 流程编号 | 流程名称 | 入口 | 核心步骤 |
|---------|---------|------|---------|
| F1 | 西药处方-搜索药品→图文问诊提交 | P01 点击"西药处方" | 搜索药品→配置用法用量→选诊断→填就诊人信息→回答5个预诊问题→提交 |
| F2 | 中药处方-普通搜索→图文问诊提交 | P01 点击"中药处方" | 搜索药材→配置用量/剂数/煎法→搜索选诊断→填就诊人信息→回答2个预诊问题→提交 |
| F3 | 中药处方-经典方去开方→提交 | Step1 点击"选择经典方"→"去开方" | 选经典方→(追加/覆盖)→调整参数→后续同F2 |
| F4 | 经典方模板管理(CRUD) | 中药Step1 "选择经典方" | 新增/编辑/删除经典方 |

### 4.2 西药处方三步向导

| 步骤 | 页面 | 核心功能 | 需求来源 |
|------|------|---------|---------|
| Step1 | 药品清单 | 搜索药品(支持69码/名称/厂家，空格分隔多条件)→选择药品→加入清单→表格展示(名称/规格/厂家/用法/单次用量/用药频次/操作)→处方金额(选填)→诊断标签选择 | 业务流程§2.1 |
| Step2 | 就诊人信息 | 姓名*(combobox-textbox)/性别*(radio,默认男)/年龄*(spinbutton)/身份证(选填)/电话(选填)/首诊机构(选填)/首诊时间(选填,date-picker只读) | 业务流程§2.1 |
| Step3 | 预诊问答 | 5个问题(Q1-Q5)→诊断锁定显示(🔒)→图文问诊/视频问诊提交 | 业务流程§2.1、§3.3 |

### 4.3 中药处方三步向导（与西药差异点）

| 差异维度 | 西药 | 中药 | 来源 |
|---------|------|------|------|
| 搜索placeholder | 商品名称或69码 | 中药材名称 | §5.1 |
| 药品展示 | 表格7列(含用法/频次) | 卡片式(名称+用量+单位) | §2.2 |
| 单药控制 | 用法/单次用量/用药频次 | 仅用量+单位 | §2.2 |
| 全局设置 | 无 | 剂数/煎法/每日剂数/每日频次 | §2.2 |
| 诊断选择 | 标签点击 | 弹窗搜索→选择→确定 | §3.2 |
| 经典方 | ❌ | ✅ 选择经典方 | §2.2 |
| 预诊问题 | Q1-Q5(5个) | Q1-Q2(2个) | §3.3 |

### 4.4 经典方CRUD

| 操作 | 路由 | 关键行为 | 来源 |
|------|------|---------|------|
| 列表 | `/online-consultation/prescription-template?from=chinese-prescription` | 搜索、分页(10条/页) | §2.4 |
| 新增 | `/online-consultation/prescription-template/create` | 名称+总剂数+每日剂数+煎法+每日服用+药材组成→保存 | §F4a |
| 编辑 | `/online-consultation/prescription-template/edit/{uuid}` | 预填充→修改→保存 | §F4b |
| 删除 | 弹窗确认 | "确认删除该模板？删除后无法恢复"→确定/取消 | §F4c |
| 去开方 | 有药材→弹窗 | 取消/追加药材(同名覆盖)/药材覆盖 | §3.1 |

## 5. 关键功能规则

### 5.1 搜索规则

| 规则编号 | 规则描述 | 适用范围 | 来源 |
|---------|---------|---------|------|
| SR01 | 西药搜索支持69码/商品名称/厂家，空格分隔多条件 | 西药Step1 | §5.1 |
| SR02 | 中药搜索仅支持药材名称 | 中药Step1 | §5.1 |
| SR03 | 搜索无结果显示默认提示信息 | 全部 | §3.5 |
| SR04 | 搜索历史API支持，可获取用户历史搜索关键词 | 西药 | 探索记录第九章 |

### 5.2 药品选择与清单规则

| 规则编号 | 规则描述 | 适用范围 | 来源 |
|---------|---------|---------|------|
| PR01 | 药品可跨页多选，累计计数 | 全部 | §2.1 |
| PR02 | 西药每味药独立配置用法(combobox)、单次用量(spinbutton+单位)、用药频次(combobox) | 西药 | §2.1 |
| PR03 | 中药全局配置剂数(spinbutton)、煎法(combobox)、每日剂数(combobox)、每日频次(combobox) | 中药 | §2.2 |
| PR04 | 中药单味药仅配置用量(spinbutton)+单位(combobox) | 中药 | §2.2 |
| PR05 | 中药"每剂 N 味药"提示根据药材数动态更新 | 中药 | §2.2 |
| PR06 | 药品清单为空时无法进入下一步 | 全部 | §6.1 |

### 5.3 诊断规则

| 规则编号 | 规则描述 | 适用范围 | 来源 |
|---------|---------|---------|------|
| DR01 | 西药诊断由后台配置，标签点击选择（互斥） | 西药 | §3.2、Q9 |
| DR02 | 中药诊断通过弹窗搜索选择→确定确认 | 中药 | §3.2 |
| DR03 | 诊断在Step1选择后在Step3锁定显示(🔒图标)，可更改 | 全部 | §2.1、§2.2 |

### 5.4 经典方规则

| 规则编号 | 规则描述 | 来源 |
|---------|---------|------|
| CFR01 | 经典方去开方时，若清单为空→直接加载；若已有药材→弹窗追加/覆盖选择 | §3.1 |
| CFR02 | 追加药材时保留已有+追加经典方；同名药材覆盖用量 | §3.1 |
| CFR03 | 药材覆盖时清空已有，替换为经典方药材 | §3.1 |
| CFR04 | 经典方删除需二次确认 | §F4c |
| CFR05 | 编辑/新增取消时有"确认放弃编辑？未保存的内容将丢失"确认 | §F4a/§F4b |

### 5.5 提交与校验规则

| 规则编号 | 规则描述 | 来源 |
|---------|---------|------|
| SUB01 | 预诊问题非实时校验，点击提交按钮时才校验 | §3.4 |
| SUB02 | 未全部回答时提示"请回答完所有问题！"阻止提交 | §3.4 |
| SUB03 | 图文问诊消耗图文账户额度，视频问诊消耗视频账户额度 | Q7 |
| SUB04 | 提交后不可取消 | Q3 |
| SUB05 | 提交成功显示二维码+"问诊已提交"，需微信小程序扫码继续 | §2.1 |

## 6. 测试要素清单

### 6.1 字段类型汇总

| 字段 | 类型 | 校验特性 |
|------|------|---------|
| 西药搜索框 | textbox | 支持空格分隔多关键词 |
| 中药搜索框 | textbox | 单一名称搜索 |
| 单次用量 | spinbutton | 数字，有+/-按钮，支持小数(中药) |
| 剂数 | spinbutton | 数字，有+/-按钮(最小1) |
| 姓名 | combobox-textbox | 必填 |
| 性别 | radio | 必填，默认"男" |
| 年龄 | spinbutton | 必填，仅数字 |
| 身份证 | textbox | 选填 |
| 电话 | combobox-textbox | 选填 |
| 首诊机构 | textbox | 选填 |
| 首诊时间 | date-picker(readonly) | 选填，仅日历选择 |
| 处方金额 | textbox | 选填 |
| 用法/频次/煎法等 | combobox | 预定义选项 |

### 6.2 状态

| 状态 | 说明 |
|------|------|
| Step1-初始 | 药品清单为空，0种药品 |
| Step1-已选药 | 药品清单有N种药品，可调整配置 |
| Step2-填写中 | 正在填写就诊人信息 |
| Step3-回答中 | 正在回答预诊问题 |
| 提交成功 | 显示二维码，问诊已提交 |

### 6.3 配置项（后台可配）

| 配置项 | 影响范围 | 来源 |
|--------|---------|------|
| 西药诊断标签列表 | Step1/Step3显示内容 | Q9 |
| 预诊Q5疾病选项 | Step3 Q5问题选项 | Q5 |
| 经典方列表 | 中药Step1可选模板 | §2.4 |

### 6.4 权限

- 仅已登录药店机构用户可访问在线问诊模块（未登录/无机构用户不在范围）
