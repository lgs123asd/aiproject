# 03-首页与导航 — 需求理解

> 来源：`需求内容/03-首页与导航.md`
> 原文档：§3.2 首页模块（布局定稿）、附录 B 首页布局视觉草稿

## 1. 模块名称

首页与导航

## 2. 模块目标

| 目标 | 说明 | 来源 |
|---|---|---|
| 首页展示 | 按纵向流式布局展示五大核心区域，各区域除 Banner 外均支持后台配置显隐与排序 | §3.2 |
| 导航分发 | 通过 Banner、服务图标栏、动态活动栏将流量分发至详情页、活动专区、积分商城等子页面 | §3.2 |
| 商品曝光 | 热门排行和普通商品栏提供商品发现路径，促进转化 | §3.2 序号4/5 |
| 后台可控 | 运营可在后台动态配置各区域的图片、路由、显隐、排序，无需发版 | §3.2 总述 |

## 3. 涉及角色

| 角色 | 涉及范围 | 来源 |
|---|---|---|
| 普通用户（买家） | 浏览首页、点击跳转、调节数量、加入购物车 | §3.2 |
| 运营人员 | 后台配置 Banner/服务图标/动态活动栏/区域显隐与排序 | §3.2 各区域配置项 |
| 系统 | 自动轮播、计算热门排行、加载商品瀑布流 | §3.2 |

## 4. 核心业务流程

### 4.1 首页加载流程

```
用户进入首页 → 自上而下加载五大区域
  Banner 轮播区（自动播放）
  → 服务图标栏（固定5入口）
  → 动态活动栏（仅展示有"首页展示"开关的活动，每个活动独立横向滑动楼层）
  → 热门商品排行栏（Top10，默认可见前6个，可滚动）
  → 普通商品栏（分类TAB + 瀑布流 + 上拉加载更多）
```

### 4.2 各区域跳转流程

```
Banner 点击 → 活动页 / 商品详情页 / 活动专区（由后台配置决定）
服务图标-热门活动 → 活动专区聚合页
服务图标-活动抽奖 → 抽奖转盘/刮刮乐页面
服务图标-积分商城 → 积分兑换列表
服务图标-每日签到 → 签到弹窗（领取积分）
服务图标-会员中心 → 会员权益页
动态活动栏-更多 → 该活动专属详情页
热门排行-商品图 → 商品详情页
热门排行-加入购物车 → 按设定数量添加到购物车
普通商品栏-商品卡 → 商品详情页
```

## 6. 测试要素

### 6.1 五大区域结构

| 区域 | 布局特征 | 交互方式 | 配置能力 |
|---|---|---|---|
| Banner | 宽幅大图，最顶部 | 轮播+滑动+点击跳转 | 图片/链接/权重 |
| 服务图标栏 | 单行5图标 | 点击跳转/弹窗 | 图标/名称/路由 |
| 动态活动栏 | 横向滑动楼层 | 滑动+数量调节+点击更多 | 首页展示开关 |
| 热门排行 | 3列大图，定高容器 | 滚动+数量调节+加购 | 无独立配置 |
| 普通商品栏 | 2列小图，瀑布流 | TAB切换+下拉刷新+上拉加载 | 分类TAB |

### 6.2 服务图标栏路由映射

| 入口 | 目标 | 交互类型 |
|---|---|---|
| 热门活动 | 活动专区聚合页 | 页面跳转 |
| 活动抽奖 | 抽奖转盘/刮刮乐 | 页面跳转 |
| 积分商城 | 积分兑换列表 | 页面跳转 |
| 每日签到 | 签到弹窗 | 弹窗 |
| 会员中心 | 会员权益页 | 页面跳转 |

### 6.3 热门排行展示规则

| 参数 | 值 | 来源 |
|---|---|---|
