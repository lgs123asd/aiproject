# 05-购物车与优惠结算 — 需求理解

> 来源：`需求内容/05-购物车与优惠结算.md`
> 原文档：§3.4 购物车与结算模块、附录A「选择优惠方式」弹窗

## 1. 模块名称

购物车与优惠结算

## 2. 模块目标

| 目标 | 说明 | 来源 |
|---|---|---|
| 购物车管理 | 用户可将商品加入购物车，在购物车中精细调节数量、查看活动标签 | §3.4.1 |
| 优惠互斥 | 结算时活动优惠与优惠券不可叠加，系统强制二选一，杜绝资损 | §3.4.2 / §1.2 |
| 智能推荐 | 系统默认勾选省钱最多的方案并提示用户 | §3.4.2 CK-009 |
| 选择弹窗 | 当商品有多活动冲突或结算页有活动与券冲突时，弹窗引导用户选择 | 附录A |

## 3. 涉及角色

| 角色 | 涉及范围 | 来源 |
|---|---|---|
| 普通用户（买家） | 购物车管理、查看优惠选择、操作弹窗、进入结算 | §3.4 / 附录A |
| 系统（促销计算引擎） | 计算最优方案、控制互斥置灰、执行默认选中 | §2.1 / §3.4.2 / 附录A |

## 4. 核心业务流程

### 4.1 购物车管理

```
详情页「加入购物车」→ 购物车列表
  → 数量调节（+/-按钮 / 手动输入）
  → 数量=1时「-」→ 置灰 或 提示"确认移除"
  → 非法输入 → 自动修正 + Toast 提示
  → 活动商品展示活动标签
  → 选中商品 → 进入结算
```

### 4.2 结算页优惠互斥

```
进入结算页
  → 促销计算引擎比较「活动优惠金额」vs「优惠券优惠金额」
  → 默认勾选省钱更多的一方，另一方置灰
  → 用户可见两个互斥板块：
      [活动优惠区] — 可选各活动 或 原价
      [优惠券区]   — 可选各优惠券
  → 切换规则：
      活动→券：点击置灰优惠券区 → 二次确认弹窗 → [继续]切换 / [取消]保持
      券→活动：点击置灰活动区 → 直接切换（无需二次确认）
  → 确认选择 → 继续下单
```

### 4.3 「选择优惠方式」弹窗（附录A）

```
触发：详情页多活动冲突 OR 结算页活动与券冲突
  → 弹窗展示（标题+温馨提示+两个互斥区域）
  → 系统计算最优解 → 默认选中较优方
  → 另一方 opacity 0.5 置灰
  → 用户操作：
      - 活动区内 Radio 单选（秒杀/满赠/聚划算/原价）
      - 点击置灰区域 → 切换（券→活动无需确认，活动→券需二次确认）
      - 活动/券均无 → 显示"暂无活动"/"暂无优惠券"
  → 点击[确认选择] → 关闭弹窗，应用选择
  → 点击 X → 行为未定义（风险 RK-CK-005）
```

## 6. 测试要素

### 6.1 购物车数量输入校验

| 输入类型 | 合法范围 | 处理规则 |
|---|---|---|
| 正常整数 | 1 ~ 库存上限 | 接受 |
| 小数 | — | 自动修正（具体规则待确认） |
| 负数 | — | 自动修正 |
| 超过库存 | — | 自动修正 |
| 非数字 | — | 自动修正 |
| 空值 | — | 自动修正 |
| 数量=1 点击「-」 | — | 置灰 或 确认移除提示 |

### 6.2 弹窗状态矩阵（6种状态组合）

| # | 状态 | 活动区 | 优惠券区 |
|---|---|---|---|
| S1 | 初始-活动更优 | Radio可选，默认最优活动 | 置灰 |
| S2 | 初始-券更优 | 置灰 | 可选，默认最优券 |
| S3 | 切换至券 | 置灰 | 可选 |
| S4 | 切换至活动 | Radio可选 | 置灰 |
| S5 | 无活动 | "暂无活动" | 按实际 |
| S6 | 无券 | 按实际 | "暂无优惠券" |

### 6.3 弹窗切换确认规则

| 切换方向 | 需二次确认 | 来源 |
|---|---|---|
| 活动 → 优惠券 | ✅ 是 | CK-010 / CK-014 |
| 优惠券 → 活动 | ❌ 否 | CK-015 |
| 活动内 Radio 切换 | ❌ 否 | CK-016 |
