# 非功能需求与数据字典

> 来源：原文档 §4 非功能性需求、§5 数据字典（核心表）

## 1. 模块范围

**包含：** 性能需求、安全需求、兼容性需求、核心数据库表结构。

**不包含：** 各模块功能规则（见对应模块文件）、后台配置管理（见 `08-后台运营管理.md`）。

## 2. 业务流程

本模块为横切关注点，无独立业务流程。非功能需求适用于所有功能模块。

## 3. 功能规则

### 3.1 性能需求

| 规则编号 | 规则内容 | 来源 |
|---|---|---|
| NF-001 | 首屏加载时间 ≤ 3 秒 | §4 |
| NF-002 | 支持 ≥ 500 并发用户 | §4 |
| NF-003 | 秒杀场景需具备高并发处理能力（引入队列、缓存预热） | §4 |

### 3.2 安全需求

| 规则编号 | 规则内容 | 来源 |
|---|---|---|
| NF-004 | 防 SQL 注入 | §4 |
| NF-005 | 防 XSS 攻击 | §4 |
| NF-006 | 支付与积分接口需签名验证，防止数据篡改 | §4 |

### 3.3 兼容性需求

| 规则编号 | 规则内容 | 来源 |
|---|---|---|
| NF-007 | Web 端兼容 Chrome, Firefox, Edge, Safari 主流版本 | §4 |
| NF-008 | 移动端适配 iOS/Android 主流分辨率（响应式设计） | §4 |

## 4. 字段、状态和配置

### 4.1 核心数据库表

#### Orders（订单主表）

| 字段 | 说明 | 来源 |
|---|---|---|
| order_id | 订单主键 | §5 |
| user_id | 用户ID | §5 |
| total_amount | 订单总金额 | §5 |
| promotion_info | 优惠快照（JSON），如 `{"type":"ACTIVITY", "id":123}`，用于财务对账 | §5 |

#### Promotion_Activity（活动表）

| 字段 | 说明 | 来源 |
|---|---|---|
| activity_id | 活动主键 | §5 |
| type | 活动类型 | §5 |
| rule_config | 规则配置（JSON），存储满减阶梯、秒杀价等 | §5 |
| is_show_home | 首页展示开关 | §5 |

#### Coupon_Template（优惠券模板表）

| 字段 | 说明 | 来源 |
|---|---|---|
| coupon_id | 券模板主键 | §5 |
| type | 1=商品券, 2=订单券 | §5 |
| value | 面值 | §5 |
| min_amount | 使用门槛金额 | §5 |

#### User_Coupon（用户持有券表）

| 字段 | 说明 | 来源 |
|---|---|---|
| id | 记录主键 | §5 |
| user_id | 用户ID | §5 |
| coupon_id | 券模板ID | §5 |
| status | 0=未用, 1=锁定, 2=已用, 3=过期 | §5 |

#### Points_Log（积分流水表）

| 字段 | 说明 | 来源 |
|---|---|---|
| log_id | 流水主键 | §5 |
| user_id | 用户ID | §5 |
| change_value | 积分变动值（正=获取，负=消耗） | §5 |
| related_order_id | 关联订单ID | §5 |

### 4.2 枚举值汇总

| 表.字段 | 枚举值 | 来源 |
|---|---|---|
| Coupon_Template.type | 1=商品券, 2=订单券 | §5 |
| User_Coupon.status | 0=未用, 1=锁定, 2=已用, 3=过期 | §5 |
| Orders.promotion_info.type | ACTIVITY（推导自示例），是否还有 COUPON/NONE？ | §5 |

### 4.3 兼容矩阵

| 平台 | 要求 | 来源 |
|---|---|---|
| Chrome / Firefox / Edge / Safari | 主流版本 | §4 NF-007 |
| iOS / Android | 主流分辨率，响应式设计 | §4 NF-008 |

## 6. 风险小结

| 风险编号 | 风险类型 | 风险描述 | 来源 | 对测试设计的影响 |
|---|---|---|---|---|
| RK-NF-001 | 未定义 | "首屏"具体定义未明确（哪个页面？） | §4 NF-001 | 无法确定性能测试测量目标 |
| RK-NF-002 | 未定义 | 500 并发具体场景未定义（同时在线？同时下单？） | §4 NF-002 | 无法设计并发测试场景 |
| RK-NF-003 | 未定义 | 秒杀高并发具体指标未定义（TPS/QPS？SLA？） | §4 NF-003 | 无法设计秒杀压测方案 |
| RK-NF-004 | 未定义 | "主流版本"范围未定义（兼容到哪个具体版本号？） | §4 NF-007 | 无法确定兼容测试版本覆盖 |
| RK-NF-005 | 未定义 | "主流分辨率"范围未定义（哪些分辨率？哪些设备？） | §4 NF-008 | 无法确定移动端设备矩阵 |
| RK-NF-006 | 未定义 | 支付接口签名验证具体算法未定义 | §4 NF-006 | 无法验证签名实现正确性 |
| RK-NF-007 | 未定义 | 数据字典不完整——缺少用户表、商品表、地址表、收藏表、购物车表 | §5 | 无法设计涉及缺失表的用例 |
| RK-NF-008 | 未定义 | Orders.promotion_info 中 type 枚举仅示例一条，其他值未定义 | §5 Orders | 优惠快照完整枚举不明确 |
| RK-NF-009 | 未定义 | Points_Log.change_value 精度未定义（积分是否有小数？） | §5 Points_Log | 积分计算精度不明确 |
| RK-NF-010 | 未定义 | 数据库表之间外键关系和约束未定义 | §5 | 无法设计数据完整性测试 |
