# 积分商城

> 来源：原文档 §3.6 积分商城模块

## 1. 模块范围

**包含：** 积分兑换礼品（虚拟/实物）、积分兑换订单生成、兑换记录查看（含物流状态）。

**不包含：** 积分获取规则（见 `06-个人中心.md`）、积分流水记录（见 `06-个人中心.md`）、积分商城入口导航（见 `03-首页与导航.md`）。

## 2. 业务流程

```
用户进入积分商城 → 浏览可兑换礼品列表
    → 选择礼品 → 确认兑换（仅扣减积分，无需现金）
    → 生成积分兑换订单
    → 查看兑换记录 / 物流状态
```

## 3. 功能规则

| 规则编号 | 规则内容 | 来源 |
|---|---|---|
| PM-001 | 使用积分兑换礼品，无需现金支付，仅扣减积分 | §3.6 |
| PM-002 | 生成独立的积分兑换订单 | §3.6 |
| PM-003 | 可查看物流状态（针对实物礼品） | §3.6 |

## 4. 字段、状态和配置

### 4.1 兑换规则

| 参数 | 说明 | 来源 |
|---|---|---|
| 支付方式 | 仅积分，无现金 | §3.6 PM-001 |
| 订单类型 | 独立积分兑换订单（区别于普通商品订单） | §3.6 PM-002 |
| 积分校验 | 积分余额 ≥ 兑换所需积分（推导） | §3.6 |

### 4.2 礼品类型

| 类型 | 物流状态 | 来源 |
|---|---|---|
| 虚拟礼品 | 推测无需物流（原文未明确） | §3.6 |
| 实物礼品 | 可查看物流状态 | §3.6 PM-003 |

## 5. 异常、边界和验收标准

原文 §3.6 未提供明确的异常处理或验收标准。以下为测试关注点：

| 场景 | 测试关注点 |
|---|---|
| 积分余额不足 | 兑换按钮是否置灰或提示？ |
| 积分刚好归零 | 是否正常完成兑换？ |
| 礼品库存不足 | 提示已兑完？展示库存数量？ |
| 虚拟礼品兑换后 | 发放方式（自动到账？兑换码？） |
| 实物礼品兑换后 | 是否需填收货地址？是否复用地址管理？ |
| 兑换订单取消 | 是否支持？积分退还是否扣除？ |
| 礼品下架 | 已兑换未发货订单如何处理？ |
