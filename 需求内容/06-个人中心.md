# 个人中心

> 来源：原文档 §3.5 个人中心模块

## 1. 模块范围

**包含：** 订单管理（状态流转、退款/售后入口）、会员积分（获取规则、使用方向）、收货地址管理（CRUD、默认地址）、我的收藏（商品列表、取消收藏、一键加购）。

**不包含：** 登录与账户安全（见 `02-登录与账户安全.md`）、积分商城兑换详情（见 `07-积分商城.md`）、支付流程（原文未涉及）。

## 2. 业务流程

### 2.1 订单状态流转

```
待付款 → 待发货 → 待收货 → 待评价 → 已完成
  ↓
退款/售后（原文未详述子流程）
```

### 2.2 积分生命周期

```
订单完成（状态 → 已完成）
    → 按 100元=10积分 换算发放
    → 积分到账
    → 用户可在积分商城使用积分兑换礼品
    → 积分扣减
```

### 2.3 地址管理流程

```
进入地址管理 → 查看地址列表
    → 新增地址 / 修改地址 / 删除地址 / 设置默认地址
```

### 2.4 收藏管理流程

```
进入我的收藏 → 查看收藏商品列表
    → 取消收藏 / 一键加入购物车
```

## 4. 字段、状态和配置

### 4.1 订单状态枚举

| 状态 | 说明 | 可执行操作 | 来源 |

| 待付款 | 订单已创建但未支付 | 支付、取消（推导） | §3.5 UC-001 |
