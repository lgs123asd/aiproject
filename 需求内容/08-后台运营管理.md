# 后台运营管理

> 来源：原文档 §3.7 后台运营系统（§3.7.1 活动管理、§3.7.2 优惠券管理）

## 1. 模块范围

**包含：** 活动管理（秒杀/满减/满赠/聚划算的配置）、优惠券管理（商品券/订单券的配置）、活动状态控制、首页展示开关、优惠券发行与限领规则。

**不包含：** 商品管理、用户管理（原文仅在 §2.2 功能架构中提及，无详细规则）、活动前台展示（见 `03-首页与导航.md`、`04-商品中心与展示.md`）。

## 2. 业务流程

### 2.1 活动管理流程

```
运营登录后台 → 进入活动管理
    → 选择活动类型（秒杀/满减/满赠/聚划算）
    → 配置活动参数（名称、时间、Banner、参与商品、规则JSON、投放渠道、权重、状态）
    → 保存 → 活动按配置生效
```

### 2.2 优惠券管理流程

```
运营登录后台 → 进入优惠券管理
    → 选择优惠券类型（商品券/订单券）
    → 配置券参数（面值、门槛、有效期、发行量、限领规则、适用商品范围）
    → 保存 → 用户可领取/系统发放
```

## 4. 字段、状态和配置

### 4.1 活动类型与特征

| 活动类型 | 核心特征 | 特有配置项 | 来源 |
|---|---|---|---|
| 秒杀 | 限时/限量/限购 | 秒杀价、限购数量、倒计时 | §3.7.1 AD-001 |
| 满减 | 阶梯 | 阶梯规则（满X减Y） | §3.7.1 AD-001 |
| 满赠 | 赠品管理 | 满赠门槛、赠品商品 | §3.7.1 AD-001 |
| 聚划算 | 团购 | 成团人数、团购价 | §3.7.1 AD-001 |

### 4.2 活动状态控制

| 状态 | 说明 | 前台可见性 | 来源 |
|---|---|---|---|
| 启用 | 活动进行中 | 可见、可参与 | §3.7.1 AD-009 |
| 停用 | 活动关闭 | 不可见 | §3.7.1 AD-009 |
| 预热 | 活动即将开始 | **未定义**（是否可见？可提前加购？） | §3.7.1 AD-009 |

### 4.3 活动表结构（来自 §5 数据字典）

| 字段 | 说明 | 来源 |
|---|---|---|
| activity_id | 活动主键 | §5 Promotion_Activity |
| type | 活动类型 | §5 Promotion_Activity |

### 4.4 优惠券表结构与状态枚举

| 表 | 字段 | 说明 | 来源 |
|---|---|---|---|
| Coupon_Template | coupon_id / type(1=商品券,2=订单券) / value / min_amount | 券模板 | §5 |
| User_Coupon | id / user_id / coupon_id / status | 用户持有券 | §5 |

**User_Coupon.status 枚举：**

| 状态码 | 状态名 | 说明 | 来源 |
|---|---|---|---|
| 0 | 未用 | 已领取，可使用 | §5 User_Coupon |
| 1 | 锁定 | 已选中在结算中（未完成支付） | §5 User_Coupon |
| 2 | 已用 | 已使用 | §5 User_Coupon |
| 3 | 过期 | 超过有效期 | §5 User_Coupon |

## 5. 异常、边界和验收标准

原文未提供明确验收标准。以下为测试关注点：

| 场景 | 测试关注点 |
|---|---|
| 同一商品参与多个同期活动 | 是否允许？前台如何展示冲突？ |
| 活动规则 JSON 格式错误 | 保存时校验？错误提示？ |
| 预热状态活动 | 用户能否看到？加购？购买？ |
| 活动启用后修改规则 | 已下单未支付用户是否受影响？ |
| 优惠券发行量已领完 | 用户端提示？ |
| 有效期"领券后N天" | 精确到小时还是天？跨日边界？ |
| 优惠券锁定后支付超时 | 是否自动释放？ |
| 多张同类型优惠券 | 是否可以叠加使用？ |
