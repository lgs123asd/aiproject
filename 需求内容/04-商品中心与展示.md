# 商品中心与展示

> 来源：原文档 §3.3 商品中心模块（§3.3.1 商品列表页、§3.3.2 商品详情页）、§3.8 活动专区页面

## 1. 模块范围

**包含：** 商品列表页展示与筛选排序、商品详情页展示与活动标识、数量调节器通用行为、多活动冲突拦截触发条件、活动专区页面。

**不包含：** 购物车中的数量调节行为（见 `05-购物车与优惠结算.md`）、优惠互斥弹窗详细交互（见 `05-购物车与优惠结算.md` 附录A部分）、活动后台配置（见 `08-后台运营管理.md`）。

## 2. 业务流程

### 2.1 商品浏览流程

```
首页/搜索 → 商品列表页（网格/列表，筛选排序）
    → 点击商品 → 商品详情页（活动标识、多活动检测）
    → 若有多种活动冲突 → [触发"选择优惠方式"弹窗，详见 05-购物车与优惠结算.md]
    → 调节数量 → 加入购物车 / 立即购买
```

### 2.2 活动专区入口流程

```
首页服务图标"热门活动" → 活动专区聚合页（卡片列表，标注类型标签）
    → 点击活动卡片 → 该活动的商品列表页
```

## 5. 异常、边界和验收标准

### 5.1 原文明确的验收标准

| 编号 | 内容 | 来源 |
|---|---|---|
| PD-A01 | 数量调节：手动输入失焦后校验合法性 | §3.3.1 PD-006 |

### 5.2 隐含边界（测试关注点）

| 场景 | 测试关注点 |
|---|---|
| 商品库存为 0 | 商品是否展示？调节器是否可用？按钮是否置灰？ |
| 商品库存为 1 | "+" 按钮上限；手动输入 >1 的校验 |
| 手动输入小数（如 1.5） | 校验行为——拒绝？向下取整？Toast 提示？ |
| 手动输入负数 | 校验行为 |
| 手动输入超大数 | 自动修正为库存上限？还是拒绝？ |
| 手动输入非数字字符 | 校验行为 |
| 空品牌/分类筛选结果 | 空状态展示 |
| 商品仅参与一种活动 | 是否弹出"选择优惠方式"弹窗？（预期：不弹出） |
| 商品不参与任何活动 | 活动标识区域如何展示？ |
