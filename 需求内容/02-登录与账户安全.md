# 登录与账户安全

> 来源：原文档 §3.1 登录与账户模块

## 1. 模块范围

**包含：** 用户注册、登录（密码/验证码）、密码安全存储、登录状态保持。

**不包含：** 个人中心资料管理（见 `06-个人中心.md`）、后台用户管理（见 `08-后台运营管理.md`）、支付安全（见 `09-非功能需求与数据字典.md`）。

## 2. 业务流程

原文未提供登录流程图或详细流程步骤。以下从规则推导：

```
注册入口 → 手机号/邮箱注册 → 设置密码 → 注册成功
登录入口 → 选择方式（密码登录 / 验证码快捷登录）→ 验证通过
    → Token/Cookie 签发（7天有效）→ 进入首页
```
