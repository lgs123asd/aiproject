# 首页与导航

> 来源：原文档 §3.2 首页模块（布局定稿）、附录 B 首页布局视觉草稿

## 1. 模块范围

**包含：** 首页五大核心区域（Banner 轮播区、服务图标栏、动态活动栏、热门商品排行栏、普通商品栏）的布局、交互和后台配置能力。

**不包含：** 活动详情页具体规则（见 `04-商品中心与展示.md`）、积分商城具体兑换（见 `07-积分商城.md`）、活动后台配置（见 `08-后台运营管理.md`）。

## 2. 业务流程

### 2.1 首页整体布局（自上而下）

```
+------------------+
|  Banner 轮播区     |  自动轮播 + 手动滑动，点击跳转
+------------------+
|  服务图标栏        |  5个入口：热门活动/抽奖/积分商城/签到/会员
+------------------+
|  动态活动栏        |  横向滑动楼层（按后台开关控制显隐）
+------------------+
|  热门商品排行栏    |  前10名，大图卡片，3列，默认显示前6个，可滚动
+------------------+
|  普通商品栏        |  瀑布流，分类TAB，每行2个，下拉刷新+上拉加载
+------------------+
```

### 2.2 服务图标栏导航路由映射

```
热门活动 → 活动专区聚合页
活动抽奖 → 抽奖转盘/刮刮乐页面（奖品：优惠券或积分）
积分商城 → 积分兑换列表
每日签到 → 签到弹窗 → 领取积分
会员中心 → 会员权益页
```

## 4. 字段、状态和配置

### 4.1 首页区域配置项

| 区域 | 后台配置项 | 来源 |
|---|---|---|
| Banner | 图片 URL、跳转链接、排序权重 | §3.2 序号1 |
| 服务图标栏 | 图标样式、名称、跳转路由 | §3.2 序号2 |
| 动态活动栏 | 活动"首页展示"开关（来自活动管理） | §3.2 序号3 |
| 全局 | 除 Banner 外各区域均支持后台配置显隐与排序 | §3.2 总述 |

### 4.2 动态活动栏展示状态

| 活动状态 | 首页是否展示 | 来源 |
|---|---|---|
| 开启"首页展示"开关 | 是（横向滑动楼层） | §3.2 序号3 |
| 关闭"首页展示"开关 | 否 | §3.2 序号3（推导） |

## 5. 异常、边界和验收标准

### 5.1 原文明确的边界

| 编号 | 边界/异常 | 内容 | 来源 |
|---|---|---|---|
| HP-B01 | 热门排行可见范围 | 默认可见前6个（2行），第7-10名需滚动查看 | §3.2 序号4 |

### 5.2 隐含边界（测试关注点）

| 场景 | 测试关注点 |
|---|---|
| Banner 数量为 0 | 轮播区是否隐藏或显示占位？ |
| 所有区域均设为隐藏 | 首页展示什么？ |
| 动态活动数为 0 | 动态活动栏是否隐藏？ |
| 热门商品不足 10 个 | 排行栏如何处理？ |
| 普通商品栏数据为空 | 瀑布流展示什么？ |
| 下拉刷新失败 | 是否展示错误提示？重试机制？ |
